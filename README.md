# עמדת איתור סטודנטים – מדריך העלאה ל-Render

האתר כולל:
- **דף כניסה** עם סיסמה. רשימת הסטודנטים מכילה מידע אישי, ולכן רק הצוות נכנס.
- **דף איתור** (הדף הראשי): סורקים ברקוד או מקלידים מספר זהות ← מוצגים כל הפרטים מהאקסל ← בוחרים מספר כרטיסים (1–5), מקלידים מספר חשבונית ← **שמירה**.
- אם הסטודנט כבר רכש, מופיעה הודעה כתומה עם הכמות, החשבונית והשעה. אפשר לעדכן.
- אם מספר החשבונית כבר רשום אצל סטודנט אחר, מופיעה אזהרה.
- **רשימת רכישות**: כל מה שנמכר, מכל העמדות, עם חיפוש.
- **ניהול** (רק בסיסמת מנהל): העלאת קובץ האקסל, הורדת כל הרכישות לאקסל, ומחיקת רכישה.

---

## שלב 1: להעלות את הקבצים ל-GitHub (פעם אחת, כ-5 דקות)

Render לוקח את האתר מ-GitHub, אז הקבצים צריכים להיות שם.

1. נכנסים ל-https://github.com ופותחים חשבון אם אין.
2. לוחצים **New** (או ➕ למעלה ← New repository).
3. שם: `student-tickets`. מסמנים **Private** (פרטי). לוחצים **Create repository**.
4. בעמוד שנפתח לוחצים על הקישור **uploading an existing file**.
5. פותחים את קובץ ה-ZIP במחשב, וגוררים לחלון את **כל התוכן של התיקייה** (הקבצים והתיקייה `public`, לא את התיקייה עצמה).
6. לוחצים **Commit changes**.

> ⚠️ **לא להעלות את קובץ האקסל של הסטודנטים ל-GitHub.** הוא מועלה מאוחר יותר דרך עמוד הניהול באתר.

## שלב 2: להפעיל את האתר ב-Render (כ-5 דקות)

1. נכנסים ל-https://render.com ← **Get Started** ← נרשמים **עם חשבון ה-GitHub**.
2. למעלה: **New ➕** ← **Blueprint**.
3. מחברים את GitHub אם מתבקשים, ובוחרים את `student-tickets`.
4. Render קורא את קובץ ההגדרות ומבקש שני ערכים:
   - `STAFF_PASSWORD`: הסיסמה שהצוות בעמדות יקליד.
   - `ADMIN_PASSWORD`: סיסמה אחרת, רק לך (להעלאת האקסל ולהורדת הנתונים).
5. לוחצים **Apply** / **Deploy Blueprint** ומחכים כמה דקות עד שמופיע **Live**.
6. בשירות `student-tickets` מופיעה כתובת כמו `https://student-tickets-xxxx.onrender.com`. זה האתר.

## שלב 3: להעלות את רשימת הסטודנטים

1. נכנסים לכתובת האתר עם **סיסמת המנהל**.
2. לוחצים **ניהול** ← גוררים את קובץ האקסל.
3. צריכה להופיע הודעה "נטענו X סטודנטים".

הקובץ צריך שורת כותרות, ואחת העמודות צריכה להיקרא מ"ז / ת.ז / תעודת זהות. כל שאר העמודות יוצגו בעמדה כמו שהן.
כשמתעדכנת רשימה, מעלים קובץ חדש. הוא מחליף את רשימת הסטודנטים, והרכישות שכבר נרשמו נשמרות.

## שלב 4: בעמדות המכירה

- פותחים את כתובת האתר בכל מחשב, מקלידים את **סיסמת הצוות** ושם עמדה (למשל "עמדה 1"). המחשב נשאר מחובר כ-14 שעות.
- **סורק ברקוד:** כל סורק USB רגיל עובד. הוא "מקליד" את המספר ולוחץ Enter. אין צורך להתקין כלום. מספיק שהדף פתוח.
- `Esc` מנקה את המסך ללקוח הבא.

## חשוב לדעת על התוכנית החינמית של Render

- **"שינה":** אם אף אחד לא נכנס לאתר כ-15 דקות, הוא נרדם, והכניסה הבאה לוקחת כדקה. **פתחו את האתר כמה דקות לפני תחילת המכירה.** בימי מכירה עמוסים כדאי לשדרג את השירות לתוכנית **Starter** (בתשלום חודשי קטן). כך הוא לא נרדם, ואפשר לחזור לחינמי אחרי האירוע.
- **בסיס הנתונים החינמי נמחק אחרי 30 יום.** בסוף המכירה (וגם באמצע, ליתר ביטחון) היכנסו ל**ניהול ← הורדה לאקסל** כדי לשמור גיבוי.

## בדיקה על המחשב שלך (לא חובה)

אם מותקן Node.js: פותחים חלון פקודות בתיקייה ומריצים `node server.js`, ואז נכנסים ל-http://localhost:3000.
סיסמאות הבדיקה: `staff` לצוות, `admin` למנהל. הנתונים נשמרים בתיקייה `data`.
