# טופס השלמת פרטים (complete-form)

שירות נפרד מאתר הרישום. כל רוכש מקבל קישור אישי `/c/<token>` להשלמת המייל והטלפון שלו ופרטי האורחים.

משתני סביבה ב-Render:
- `DATABASE_URL` – אותו מסד נתונים של אתר הרישום (טבלאות `cf_` בלבד; לא נוגע בטבלאות הקיימות).
- `ADMIN_PASSWORD` – סיסמה לדף המעקב `/admin` (שם משתמש: כל ערך).
- `SEED_B64` – רשימת הנמענים (JSON מכווץ ב-base64). נטען בכל עלייה; תשובות קיימות נשמרות.
- `DEADLINE` – מועד אחרון (ISO, UTC). ברירת מחדל: שלישי 27.10 20:00 שעון ישראל.

דפים: `/c/<token>` טופס · `/admin` מעקב · `/admin/export.csv` ייצוא לאקסל.
